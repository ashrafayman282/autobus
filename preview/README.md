## هيكل المشروع

```
index.html              صفحة واحدة (SPA) بتحمّل الملفات اللي تحت
manifest.webmanifest    إعدادات التطبيق (PWA)
css/
  base.css              التنسيقات الأساسية والألوان
  theme.css             الوضع الليلي/النهاري
  platform.css          عناصر المنصة
  games.css             شكل الألواح والقطع (شطرنج، داما، لودو، كروت...)
  polish.css            الواجهة الجديدة: الصفحة الرئيسية، الحركة، المؤثرات
js/
  fb.js                 استيراد Firebase (المزامنة الأونلاين)
  app.js                المحرك: الحالة، الغرف، الرندر، الألعاب
  data/bank.js          بنك الأسئلة المصري (114 سؤال إضافي + التصنيفات)
  games/rules.js        دليل اللعب لكل لعبة
  games/art.js          أغلفة SVG قديمة (احتياطية)
assets/
  img/games/*.svg       غلاف مرسوم لكل لعبة (16)
  img/hero.svg          خلفية الملاهي
  img/logo.svg          اللوجو
  audio/*.mp3           أصوات حيوانات حقيقية (بطة، قطة، كلب، حمار، ضحك)
```

## التشغيل محليًا

الموقع بيستخدم ES Modules، فمحتاج سيرفر بسيط (مش هيفتح بـ `file://`):

```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

## النشر على GitHub Pages (مجاني)

1. ارفع الملفات على الفرع `main` في فولدر `preview/`.
2. من Settings → Pages اختار الفرع `main` والفولدر `/ (root)` أو `/preview`.
3. استنى دقيقة، واللينك هيبقى: `https://<user>.github.io/<repo>/preview/`

مفيش build ولا npm ولا أي خطوة إضافية — الملفات جاهزة للنشر زي ما هي.

## الأدوات المجانية المستخدمة

- HTML + CSS + JavaScript عادي (من غير أي framework).
- Firebase Realtime Database + Auth (الخطة المجانية) للمزامنة بين اللاعبين.
- Web Audio API للأصوات والموسيقى (من غير ملفات موسيقى خارجية).
- SVG مرسوم يدويًا لكل الرسومات.
- Google Fonts: Cairo + Lalezar.
